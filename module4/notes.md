# Module 4 - Git and GitHub

## What I Learned

- Git tracks changes to source code and maintains version history.
- The three zones of Git are the working directory, staging area,
  and repository.
- Git add stages changes for the next commit.
- Git commit saves changes to the local repository.
- Git push uploads local commits to GitHub.
- Branches allow independent development without affecting main.
- Pull requests allow changes to be reviewed before merging.
- Git pull retrieves changes from the remote repository.

## Practical Experience

I created a GitHub repository, organized my previous Java
assignments, and committed each module separately.

I also learned how to configure Git, authenticate using
GitHub CLI, and push my local repository to GitHub.
